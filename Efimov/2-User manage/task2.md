
# Запрещаем

1. Запретите пользователю user1 из предыдщуего задания выполнять вход в систему
    - sudo usermod -s /usr/sbin/nologin user1 (или sudo usermod -L user1 для блокировки пароля)

2. Как вы это сделали?
    - С помощью команды usermod изменил оболочку (shell) пользователя на nologin. Теперь при попытке входа система сразу завершит сеанс, так как /usr/sbin/nologin не является командным интерпретатором.

3. Какие ещё способы это сделать вы знаете?
    - sudo passwd -l user1 — блокировка пароля (Lock). К хешу пароля в /etc/shadow добавляется восклицательный знак, делая его невалидным
    - sudo usermod -e 1 user1 — установка даты истечения учетной записи на прошедшую дату
    - Ручной метод: добавить символ ! или * перед зашифрованным паролем пользователя в файле /etc/shadow

4. Можно ли создать пользователей с одинаковыми username?
    - Нет, т.к. имя пользователя должно быть уникальным идентификатором в рамках одной системы. Технически база данных пользователей не позволит создать дубликат имени
