# ФС

1) Какие файловые системы вы знаете?
   - FAT32, NTFS, exFAT (Windows)
   - ext4, Btrfs, XFS, ZFS (Linux)
   - APFS, HFS+ (macOS)

2) Как можно классифиировать файловые системы? в чём отличия??
   - Дисковые: хранятся на физических носителях (ext4, NTFS). Отличаются структурой хранения данных
   - Сетевые: обеспечивают доступ к файлам по сети (NFS, CIFS/SMB)
   - Виртуальные (псевдо-ФС): интерфейсы к ядру в оперативной памяти (procfs, sysfs)
   - Журналируемые: записывают изменения в журнал для защиты от сбоев (ext4, XFS). В отличие от нежурналируемых (ext2), они быстрее восстанавливаются

3) Какие файловые системы используются в linux?
   - Стандартная для большинства дистрибутивов - ext4
   - Корпоративный стандарт для больших данных - XFS
   - Современная с поддержкой снимков и RAID - Btrfs
   - Файловая система в ОЗУ - tmpfs

4) Как можно создать файловую систему на диске?
   - С помощью команд семейства mkfs
   - Пример: sudo mkfs.ext4 /dev/sdb1

5) Как можно подключить диск в систему, что такое монтирование?
   - Монтирование - это процесс привязки файловой системы устройства к конкретной точке (папке) в дереве каталогов
   - Команда подключения: sudo mount /dev/sdb1 /mnt
   - Команда отключения: sudo umount /mnt

6) файловая система procfs, cifs, tpmfs,sysfs. В чём особенности каждой из них? Вывести каталоги к которым примонтированы эти файловые системыю
   - procfs: интерфейс к структурам данных ядра и процессам. Монтируется в /proc
   - cifs: протокол доступа к файлам Windows по сети. Обычно монтируется в /mnt или /media
   - tmpfs (в вопросе tpmfs): хранит данные в оперативной памяти. Монтируется в /run, /dev/shm, /tmp
   - sysfs: экспорт информации об аппаратных устройствах и драйверах из ядра. Монтируется в /sys

7) Как можно получить информацию о системе используя лишь команду cat? вывести ифонмацию о процессоре и состоянии памяти системы
   - Информация о процессоре: cat /proc/cpuinfo
   - Информация о памяти: cat /proc/meminfo
   - Информация о разделах дисков: cat /proc/partitions
