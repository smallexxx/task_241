# Струтура каталогов

1) Какая структура каталогов в linux? выведите список файлов в корне системы
   - В Linux используется иерархическая структура каталогов, начинающаяся с корня /
   - Список файлов в корне системы: ls -F /

2) Где хранятся папки пользователей в системе?
   - В каталоге /home

3) Где домашняя папка суперпользователя?
   - В каталоге /root

4) Где хранятся основые конфигурационные файлы в системе?
   - В каталоге /etc

5) ЧТо за папки /bin,/sbin,usr/sbin,/usr/sbin
   - /bin - содержит основные исполняемые файлы (команды), доступные всем пользователям
   - /sbin - содержит системные исполняемые файлы для администрирования (обычно для root)
   - /usr/bin - дополнительные пользовательские команды и программы
   - /usr/sbin - дополнительные системные команды для администрирования
