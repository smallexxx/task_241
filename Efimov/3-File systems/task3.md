# Продолжаем

1. Выведите содержимое fstab. Что хранится в fstab?
   - cat /etc/fstab
   - В fstab хранится информация о файловых системах, которые должны автоматически монтироваться при загрузке системы

2. Добавьте в виртуальную машину ещё один диск
   - Выполнил в настройках виртуалки (раздел Носители - Контроллер SATA - Добавить жесткий диск)

3. Узнайте как ситема видит ваш диск - выведите информацию о блочных устройствах
   - lsblk

4. С помощью полученной информации создайте на диске таблицу разделов и фаловую систему ext4
   - Создание таблицы разделов (на примере диска sdb): sudo fdisk /dev/sdb (далее команды n, p, 1, w)
   - Создание файловой системы: sudo mkfs.ext4 /dev/sdb1

5. Примонитруте диск в каталог /mnt
   - sudo mount /dev/sdb1 /mnt

6. Зайдите в каталог и создайте там файлы
   - cd /mnt && sudo touch file1 file2 file3

7. Отмонтируйте диск и проверье остались ли файлы
   - sudo umount /mnt
   - Проверяю: ls /mnt 

8. Сделайте так чтобы диск автоматически подключался при загрузке систем ( добавьте информацию о нём с fstab)
   - узнаем UUID диска: blkid /dev/sdb1
   - Добавляем строку в /etc/fstab: UUID=ваш_uuid /mnt ext4 defaults 0 2

9. Проверьте корретность записанных в fstab данных перед перезагрузкой
   - sudo mount -a
   - команда не выдала ошибок, значит fstab настроен верно

10. Перезагрущите систему и убедитесь что диск был подключён к системе
    - sudo reboot
    - проверил после входа: df -h или lsblk
