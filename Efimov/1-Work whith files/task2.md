# Перенаправляем

1) Как работают команды >, >>?
    > - перенаправляет stdout в файл, перезаписывая его. Пример: ls > files.txt
    >> - перенаправляет stdout в файл, дополняя его. Пример: date >> log.txt
2) Что такое перенаправление ввода? stderr,stdout;
    - Перенаправление ввода (<) — передача данных из файла в программу (stdin). Пример: cat < file.txt
    - stdout (1) — поток нормального вывода
    - stderr (2) — поток вывода ошибок
3) Выести содержание файла не используя текстовые редакторы;
    - cat имя_файла (полностью), head имя_файла (первые 10 строк), tail имя_файла (последние 10 строк)
4) Создать файл с содержимым не используя текстовые редактор;
    - echo "содержимое" > файл.txt или printf "строка\n" > файл.txt
5) пернеаправить stdout в stderr и обратно на примере команды kinit, ping, tracert
    - stdout в stderr: ping -c 1 8.8.8.8 1>&2 (результат уйдет в поток ошибок).
    - stderr в stdout: kinit user 2>&1 (ошибки аутентификации уйдут в основной поток).
6) чем отличаются stdout и stderr
    - stdout - предназначен для полезных данных, которые можно передать другой команде через конвейер (|).
    - stderr - предназначен для служебных сообщений и ошибок, чтобы они не перемешивались с данными.
7) что такое stdin?
    - стандартный поток ввода данных (по умолчанию с клавиатуры).
8) как отправить весь вывод команды в пустоту?
    - команда > /dev/null
