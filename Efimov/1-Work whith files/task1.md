# Работа в консольке

1) Переместиться между директориями 
    - cd (переход назад - cd .., в домашнюю директорию - cd ~)
2) Вывести список файлов в директории 
    - ls (подробный список - ls -l)
3) Вывести список Всех файлов в директории 
    - ls -a 
4) Создать папку с подпапками 
    - mkdir -p dir1/dir2/dir3
5) Внутри папки создать файлик и записать в него что-нибудь 
    - echo "text" > dir1/file.txt (дописать в конец - >>)
6) Переместить файл из одно директории в другую 
    - mv /home/user/dir1/file.txt /home/user/dir2/
7) скопировать файл из одной директории в другую 
    - cp /home/user/dir1/file.txt /home/user/dir2/
8) переименовать файл 
    - mv a.txt b.txt
9) сравнить содержимое файла 
    - diff file1.txt file2.txt (визуальное сравнение - sdiff file1.txt file2.txt)
10) отсортировать содержимоей файла по возрастанию и убыванию 
    - sort file.txt (по возрастанию), sort -r file.txt (по убыванию)
11) удалить все папки и файлы
    - rm -rf name_dir (удаление конкретной папки), rm -rf * (очистка текущей директории)
